# AI Prompt and Revision Records

Folders `A/` through `J/` are reserved for real track implementation history. `_cross_track/` contains actual planning, setup, and infrastructure interactions that affect the whole repository.

Every record uses `record.json`, `prompt.md`, `response.md`, and `verification.md`. A response file may contain a relevant excerpt instead of a full export, but it must say so. Commit URLs cannot exist before publication; record the local hash first and replace/add a public link later.

Never fabricate prompts, responses, failures, screenshots, tool identities, model versions, elapsed time, or commits. If an exact model snapshot is not exposed by the tool, record that limitation explicitly.
