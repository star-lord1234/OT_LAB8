# Short Demonstration Plan

Status: scaffold only.

The final 5-10 minute demonstration must show:

1. The selected process/problem and mathematical formulation.
2. A reproducible baseline command.
3. One optimized command/method.
4. Direct correctness evidence.
5. A measured table/plot supporting an improvement, regression, or honest null result.
6. One failure/limitation and the key lesson.
7. Links to the A-J coverage and AI disclosure evidence.

Exact commands and expected outputs must be inserted only after the experiments exist.
